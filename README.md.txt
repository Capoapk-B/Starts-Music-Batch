 Starts Music Batch ♫

Starts Music Batch is a multifunctional Windows Batch script that leverages PowerShell to provide a rich set of audio tools, including a graphical media player, text-to-speech conversion, and a rudimentary music composer

 Features

 Graphical Media Player: A built-in WPF (Windows Presentation Foundation) interface powered by PowerShell to play local audio files (`mp3`, `wav`, etc) and stream live online web radios via the Radio Browser API
 Audio Book Generator: Converts UTF-8 encoded `txt` files into `wav` audio files using the native Windows Speech Synthesizer (Text-to-Speech) It automatically splits long texts into manageable chunks
 Manual Music Composer: Turns your computer keyboard into a virtual piano You can play notes in real-time, record your composition, and export it directly to a `wav` file using sine wave generation
 Random Music Generator: Automatically generates a random sequence of notes and exports them to an audio file
 File Management: Automatically creates and monitors a dedicated working directory (`Starts Music Batch`) to track your text and audio files

 Prerequisites

 Windows 10 or Windows 11
 Windows PowerShell (pre-installed on Windows)
 Ensure your `txt` files used for the Audio Book feature are encoded in UTF-8

 How to Use

1 Double-click the `pmbbat` file to launch the script
2 Upon the first launch, a folder named `Starts Music Batch` will be created in the same directory
3 Place your `txt` files (for reading) or your audio files (for the player) into this new folder
4 Use the interactive numerical menu (1-8) in the console to navigate between the different features
